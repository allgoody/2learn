## What it is

Azure is Microsoft's public cloud. It offers the same categories as any other provider — virtual machines, storage, networking, managed databases, functions — but it is strongest where an organisation already runs Microsoft software, because its identity system is the same one those organisations use for email and desktops. Where AWS grew from selling infrastructure, Azure grew from extending the enterprise estate into someone else's datacentre.

## Why it matters

For a company whose staff, servers and directories are already Microsoft, Azure is often the shortest path: existing identities, existing licences and existing tooling carry over, and the people who administer them keep their skills. That advantage is real and frequently decisive. It is also a trap if it becomes the only reason for a decision that should be about the workload, so it is worth knowing where Azure is genuinely strong and where it is merely familiar.
