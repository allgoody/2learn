## Что это такое

Основы Python — это части, из которых сделана любая программа: значения нескольких встроенных типов, имена, которые просто указывают на них, условия, циклы, функции и отступы, задающие блоки. Типы привязаны к значениям, а не к именам, проверяются во время выполнения, а аргументам функции можно давать значения по умолчанию и имена. Этого достаточно, чтобы написать законченную программу, и всё дальнейшее строится на этом.

## Почему это важно

Проектные решения языка проявляются именно здесь и определяют всё остальное. Отступы — часть синтаксиса, поэтому форматирование не вопрос вкуса и код читается одинаково везде. Типы привязаны к значениям, поэтому одно имя может хранить строку, а позже целое число, — это гибко и объясняет, почему ошибки типов возникают во время выполнения, а не при сборке. Имена — это ссылки, а не коробки, поэтому два имени могут указывать на один изменяемый объект; отсюда целое семейство ошибок, которые становятся очевидны, как только модель понята.

## Ключевые идеи

### Имена указывают на значения

Присваивание привязывает имя к объекту, а не копирует объект. Значит, два имени могут ссылаться на один список, и изменение через одно видно через другое. Типы принадлежат объектам, а не именам, поэтому одно имя можно переиспользовать для значений разных типов и поэтому проверяющему типы нужны аннотации в помощь.

```text
a = [1, 2]
b = a          -> b — тот же список, что и a
b.append(3)    -> теперь a равно [1, 2, 3]
```

### Неизменяемые и изменяемые значения ведут себя по-разному

Числа, строки и кортежи нельзя изменить после создания; списки, словари и множества можно. Именно поэтому одни значения безопасно разделять между частями программы и использовать как ключи словаря, а другие опасно передавать в функции, которые могут изменить их на месте. Выбор неизменяемого значения там, где данные меняться не должны, убирает целый класс неожиданностей.

### Отступы — это структура блоков

Фигурных скобок нет; блок задаёт согласованный отступ. Табуляции и пробелы нельзя смешивать, и интерпретатор это проверяет. Следствие — каждый файл на Python отформатирован похоже, что действительно помогает читать незнакомый код.

### Функции — объекты, а у аргументов две конвенции

Функцию можно передавать как любое другое значение, и на этом построены ключи сортировки, обратные вызовы и декораторы. Аргументы можно передавать по позиции или по имени и давать им значения по умолчанию — с известной ловушкой: изменяемое значение по умолчанию создаётся один раз и разделяется между вызовами, поэтому накапливается.

### Исключения — канал ошибок, и они должны быть конкретными

Исключение распространяется вверх по стеку вызовов, пока что-нибудь его не поймает, и тип исключения — это информация, нужная обработчику. Перехват всего скрывает как ошибки программиста, так и ожидаемые отказы, поэтому ловите самый узкий возможный тип, чтобы неожиданные проблемы оставались видны.

### Контекстный менеджер — стандартный шаблон работы с ресурсами

Файлы, блокировки и соединения поддерживают блок `with`, гарантирующий очистку даже при исключении. Он избавляет от необходимости помнить о закрытии на каждом пути, и потому это ожидаемая форма, а не украшение.

## Практика

### Покажите модель ссылок

Создайте список, присвойте его второму имени, измените через второе имя, а затем повторите то же с кортежем.

Готово, когда: вы можете объяснить, почему список изменился, а кортеж вызвал ошибку.

### Напишите функцию с безопасным значением по умолчанию

Напишите функцию с необязательным аргументом-списком, вызовите её дважды без аргумента и посмотрите на накопившийся результат; затем исправьте значение по умолчанию.

Готово, когда: два последовательных вызова без аргумента дают одинаковый результат.

## Частые ошибки

- **Изменяемое значение по умолчанию** — значение разделяется между вызовами и накапливается; исправить: используйте по умолчанию `None` и создавайте значение внутри.
- **Уверенность, что присваивание копирует** — два имени делят один объект; исправить: копируйте намеренно, когда копия нужна.
- **Перехват всех исключений** — ошибки программиста скрываются вместе с ожидаемыми отказами; исправить: ловите самый узкий полезный тип.
- **Открытие файла без контекстного менеджера** — на пути ошибки закрытие пропускается; исправить: используйте `with`.
- **Расчёт на то, что у переменной есть тип** — ошибка появляется только при исполнении этой строки; исправить: аннотируйте типы и проверяйте их на границах.
