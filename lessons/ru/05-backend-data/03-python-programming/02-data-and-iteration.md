## Что это такое

Встроенные коллекции Python — список, кортеж, словарь, множество — плюс синтаксис включений и протокол итерации, который все они реализуют. Словарь отображает ключи в значения с быстрым поиском; множество хранит уникальные значения; список — упорядоченная изменяемая последовательность, кортеж — упорядоченная неизменяемая. Итерация — это протокол, а не синтаксис: в цикле может стоять всё, что умеет выдавать значения по одному.

## Почему это важно

Выбор подходящей коллекции — самое крупное решение о производительности в обычном коде на Python, куда крупнее микрооптимизации цикла. Поиск в словаре занимает фактически константное время, а проход по списку пропорционален его длине, поэтому программа, которая ищет по списку внутри цикла, может оказаться квадратичной, не выглядя так. Итерация важна по той же причине: генератор, выдающий значения по требованию, держит память плоской там, где список хранил бы всё сразу.

## Ключевые идеи

### Четыре коллекции отвечают на разные вопросы

Список отвечает на вопрос «что стоит на позиции n» и сохраняет порядок; словарь быстро отвечает «какое значение у этого ключа»; множество быстро отвечает «есть ли это здесь» и убирает дубликаты; кортеж — это упорядоченное значение, которое нельзя изменить и потому можно использовать как ключ словаря. Выбор делают по вопросу, который код задаёт чаще всего, а не по тому, какой тип привычнее.

```text
members = [1, 2, 3]                 -> упорядочен, индексируется, поиск — скан
index   = {1: "a", 2: "b"}         -> поиск по ключу за константное время
unique  = {1, 2, 3}                -> проверка вхождения за константное время
point   = (3, 4)                   -> неизменяем, годится как ключ
```

### Включения выражают преобразование без обвязки цикла

Включение строит коллекцию из итерируемого объекта одним выражением, при необходимости с фильтром. Оно читается, пока остаётся близко к естественному языку, и становится враждебным, когда вложено или несёт побочные эффекты. Полезное правило — держать один `for` и не больше одного `if`, а иначе использовать обычный цикл.

### Итерация ленива, а генераторы делают её ленивее

В цикле `for` может стоять всё итерируемое, включая файл, курсор базы данных и генератор. Функция-генератор выдаёт значения по мере запроса, поэтому конвейер из генераторов обрабатывает по одному элементу и держит в памяти только текущий. Именно это позволяет обработать файл, который больше памяти.

```text
def rows(path):
    with open(path) as f:
        for line in f:
            yield line.strip()
```

### Сортировка и группировка опираются на ключи и словари

Сортировка принимает функцию-ключ, а не сравнение, что оставляет частые случаи короткими. Группировка — обычно словарь, значения которого списки, а приём с `setdefault` или `defaultdict` убирает ветку, иначе стоящую перед каждым добавлением. И то и другое — обычный способ превратить поток записей в структуру.

### Копирование поверхностно, пока не сказано иное

Копирование списка дублирует внешний контейнер, но не объекты внутри него, поэтому изменение вложенного списка видно через обе копии. Это та же модель ссылок, что и раньше, но на уровень глубже, и источник ошибок, которые словно бы меняют постороннее значение.

### Порядок словаря теперь гарантирован, но это не повод на него полагаться

Словари сохраняют порядок вставки, что делает их удобными для записей. Эта гарантия — про итерацию, а не про смысл: структура, у которой корректность зависит от порядка, должна быть явно упорядоченным типом, чтобы читатель видел замысел.

## Практика

### Замените квадратичный скан поиском

Возьмите функцию, которая проверяет вхождение, проходя по списку внутри цикла по другому списку, и перепишите её через множество.

Готово, когда: переписанная версия даёт те же результаты на тех же входных данных и вы можете сказать, почему её стоимость больше не пропорциональна обеим длинам.

### Обработайте большой файл лениво

Напишите конвейер из функций-генераторов, который читает файл, фильтрует строки и выдаёт преобразованное значение, и убедитесь, что используемая память не растёт вместе с файлом.

Готово, когда: файл, в несколько раз больший доступной памяти, обрабатывается успешно и даёт тот же результат, что и неленивая версия на маленьком входе.

## Частые ошибки

- **Поиск по списку внутри цикла** — стоимость становится квадратичной; исправить: используйте множество или словарь для вхождения и поиска.
- **Построение списка, когда нужен только первый подходящий элемент** — память и время уходят на значения, которые отбрасываются; исправить: используйте генератор или выйдите из цикла.
- **Поверхностное копирование вложенных структур** — внутренние объекты всё ещё общие; исправить: копируйте глубоко или, лучше, считайте данные неизменяемыми.
- **Вложенные включения ради них самих** — выражение перестаёт читаться; исправить: используйте цикл с именем для каждого шага.
- **Порядок словаря как условие корректности** — порядок идёт от вставки, а не от замысла; исправить: используйте явно упорядоченную структуру, когда порядок важен.
