## Пример 1 — Синхронное чтение на пути запроса

Сервис обслуживает проверку работоспособности и страницу отчёта. Под нагрузкой проверка работоспособности занимает секунды всякий раз, когда запрашивают отчёт, хотя два обработчика не делят между собой ничего. Обработчик отчёта ниже читает свои данные синхронно. Перепишите его так, чтобы цикл оставался свободным, пока читается файл.

```js
import { createServer } from 'node:http'
import { readFileSync } from 'node:fs'

createServer((req, res) => {
  if (req.url === '/report') {
    const config = readFileSync('./report.json', 'utf8')   // ждёт здесь
    res.end(render(config))
  } else {
    res.end('ok')
  }
}).listen(3000)
```

### Решение

```js
import { createServer } from 'node:http'
import { readFile } from 'node:fs/promises'

createServer(async (req, res) => {
  if (req.url !== '/report') return res.end('ok')
  try {
    const config = await readFile('./report.json', 'utf8')
    res.end(render(config))
  } catch (err) {
    res.writeHead(500).end('отчёт недоступен')
  }
}).listen(3000)
```

Асинхронный вызов регистрирует чтение и возвращает управление, поэтому цикл обслуживает проверку работоспособности, пока приходят байты, а путь ошибки становится обычным ответом 500 вместо необработанной ошибки, завершающей процесс. Обычная ошибка — оставить синхронную форму, потому что обработчик короток, и столкнуться с её ценой лишь тогда, когда в работе окажется второй запрос.

## Пример 2 — Вычисление, замораживающее каждый запрос

Эндпоинт подсчёта обходит большой массив вообще без await. Пока он выполняется, ждёт каждое другое соединение, а больше памяти и реплик ничего не изменили. Разбейте работу так, чтобы цикл мог переключаться между кусками.

```js
function scoreAll(rows) {
  let total = 0
  for (const row of rows) {
    total += heavyScore(row)      // пока это не вернётся, больше ничего не выполняется
  }
  return total
}
```

### Решение

```js
const yieldToLoop = () => new Promise((resolve) => setTimeout(resolve, 0))

async function scoreAll(rows) {
  let total = 0
  for (let i = 0; i < rows.length; i++) {
    total += heavyScore(rows[i])
    if (i % 1000 === 0) await yieldToLoop()
  }
  return total
}
```

Ничто не вытесняет цикл, поэтому версия выше освобождает его каждую тысячу строк и позволяет выполниться ожидающим обратным вызовам; для действительно тяжёлой работы ту же форму применяют с рабочим потоком или отдельным процессом. Лишняя память или процессоры не помогут циклу, который никогда не уступает управление, — и это и есть ошибка: задержка выглядит как проблема ёмкости, тогда как это ход цикла, который никогда не заканчивается.
