## Что это такое

Реляционная база данных хранит данные в таблицах из строк и столбцов, связывает таблицы друг с другом через общие значения ключей и отвечает на вопросы на языке SQL. Движок гарантирует, что группа инструкций либо применяется целиком, либо не применяется вовсе, и что параллельные читатели и писатели не видят незавершённую работу друг друга. Эти две гарантии вместе с планировщиком запросов, который выбирает способ выполнения, и делают её хранилищем по умолчанию для структурированных данных.

## Почему это важно

У большинства приложений есть данные, корректность которых важна: заказ, который нельзя списать дважды; баланс, который не должен уйти в минус; связь, которая не должна указывать на удалённую строку. Реляционный движок поддерживает эти свойства сам, без проверки в каждом месте приложения, — поэтому он остаётся выбором по умолчанию спустя десятилетия альтернатив. Это ещё и слой, где плохие решения обходятся дороже всего: схема и её индексы живут дольше окружающего кода приложения.
