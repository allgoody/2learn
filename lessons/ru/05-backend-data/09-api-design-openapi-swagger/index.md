## Что это такое

Формат описания HTTP API: машиночитаемый документ со списком путей, методов на каждом из них, параметров, тел запросов и ответов и кодов состояния. Поскольку он структурирован, а не написан прозой, один и тот же документ может порождать документацию, клиентские библиотеки, заглушки сервера и тесты. OpenAPI — это формат; Swagger — название семейства инструментов вокруг него.

## Почему это важно

Записанный до реализации интерфейс заставляет принять решения, которые иначе обнаруживают клиенты: что содержит запрос, как выглядит сбой, какие поля необязательны. Он же даёт одно описание, которое потребляют несколько инструментов, поэтому документация и клиентский код не могут разойтись с реализацией незаметно для тестов. Для команды, строящей обе стороны сервиса, спецификация — это контракт, позволяющий им идти параллельно.
