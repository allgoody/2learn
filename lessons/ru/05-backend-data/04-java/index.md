## Что это такое

Java — статически типизированный компилируемый язык, который выполняется на виртуальной машине. Исходный код компилируется в байт-код, а виртуальная машина исполняет этот байт-код, управляя памятью, загружая классы и оптимизируя горячий код прямо во время работы программы. Получается язык, многословный по современным меркам и необычно предсказуемый в долгоживущих проектах с большими командами, — поэтому он остаётся выбором по умолчанию в корпоративной серверной разработке.

## Почему это важно

Виртуальная машина — причина, по которой Java всё ещё выбирают: зрелая среда выполнения со сборщиком мусора и JIT-компилятором, которую настраивают два десятилетия и которая работает на любой операционной системе и архитектуре. Код компилируется один раз и выполняется всюду, где есть подходящая среда выполнения, а программа, проработавшая недели, оптимизирована настолько, насколько это возможно. Плата — память и время запуска, а ещё язык, чья церемония — типы, видимость, проверяемые исключения — одним командам кажется тяжёлой, а другим проясняющей.
