## Что это такое

RESTful API выставляет данные как ресурсы со стабильными адресами и позволяет клиентам действовать над ними, используя стандартные значения методов HTTP и кодов состояния. У коллекции есть адрес, у отдельного элемента — дочерний адрес, а создание, чтение, замена и удаление отображаются на методы, которые протокол уже определяет. Этот стиль — набор ограничений, а не спецификация, и следовать стоит тем его частям, которые делают API предсказуемым для того, кто не читал его документацию.

## Почему это важно

Предсказуемость и есть вся отдача. Когда каждый API придумывает собственные глаголы и формат ошибок, каждая интеграция превращается в разведку, а у клиентов накапливаются особые случаи. Когда соглашения соблюдены, разработчик, знающий один эндпоинт, знает форму остальных: как перечислить ресурсы, как получить один, как создать и как выглядит сбой. Кэши и прокси также зависят от того, что соглашения соблюдаются по-настоящему: чтение, которое меняет состояние, или создание, повтор которого даёт другой результат, ломают допущения посредников.
