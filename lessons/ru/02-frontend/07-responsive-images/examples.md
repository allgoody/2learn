## Пример 1 — Главное изображение, которое браузер не может оценить

У главного изображения три файла-кандидата, оно загружается отложенно и не объявляет ни отображаемую ширину, ни собственный размер. На телефоне браузер скачивает файл 1600px, и вёрстка прыгает, когда он приходит. Скажите, для чего был нужен каждый отсутствующий атрибут, затем исправьте разметку.

```html
<img
  src="hero-1600.jpg"
  srcset="hero-400.jpg 400w, hero-800.jpg 800w, hero-1600.jpg 1600w"
  loading="lazy"
  alt="A workshop at sunset"
/>
```

### Решение

```html
<img
  src="hero-800.jpg"
  srcset="hero-400.jpg 400w, hero-800.jpg 800w, hero-1600.jpg 1600w"
  sizes="(min-width: 60rem) 50vw, 100vw"
  width="1600" height="900"
  alt="A workshop at sunset"
/>
```

Без `sizes` браузер считает, что изображение занимает всю ширину окна, поэтому телефон шириной 400px всё равно проходит по критерию для самого крупного кандидата и скачивает файл, большая часть которого выбрасывается. `sizes` сообщает отображаемую ширину при каждой ширине окна — это именно та информация, которая нужна для выбора. Атрибуты `width` и `height` резервируют область 16:9 до прихода файла, поэтому текст под ним не сдвигается; CSS всё равно может задать отображаемый размер, потому что атрибуты дают только собственное соотношение сторон. А `loading="lazy"` неуместен на главном изображении: он задерживает самый крупный видимый элемент — именно то, что измеряет показатель загрузки; для изображений за пределами экрана он и предназначен.

## Пример 2 — Современный формат, за которым ничего нет

Элемент picture предлагает два современных формата и не имеет запасного варианта, поэтому браузер, не умеющий декодировать ни один из них, показывает сломанное изображение. Объясните, как браузер выбирает источник, затем сделайте запасной вариант настоящим.

```html
<picture>
  <source srcset="hero-1600.avif" />
  <source srcset="hero-1600.webp" />
</picture>
```

### Решение

```html
<picture>
  <source type="image/avif" srcset="hero-1600.avif" media="(min-width: 60rem)" />
  <source type="image/webp" srcset="hero-1600.webp" media="(min-width: 60rem)" />
  <img src="hero-1600.jpg" width="1600" height="900" alt="A workshop at sunset" />
</picture>
```

Браузер перебирает источники по порядку и берёт первый, который понимает, — поэтому современный формат идёт первым и поэтому важен атрибут `type`: без него браузер может скачать файл, который не сможет декодировать. `<img>` не является необязательным: это запасной вариант, который отрисует любой браузер, и он должен быть действительно корректным файлом, а не заглушкой. `media` у источника — то, что делает `<picture>` полезным и для смены кадра, и для формата: широкий кадр на больших экранах и высокий во всех остальных случаях; при этом `srcset` внутри него по-прежнему отвечает за разрешение.
