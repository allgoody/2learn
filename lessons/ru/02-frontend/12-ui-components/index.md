## Что это такое

UI-компонент — это самодостаточная часть интерфейса — кнопка, поле формы, карточка, диалог, — у которой есть собственный определённый интерфейс: какие входные данные она принимает, что рисует и как себя ведёт. Собрать компонент — значит решить, каким будет этот интерфейс, реализовать его один раз и использовать везде, где встречается та же задача.

## Почему это важно

Без компонентов каждый экран придумывает собственную кнопку. Кнопки расходятся по одному свойству за раз, пока продукт не начинает выглядеть собранным из трёх разных дизайнов, а изменение основного цвета не превращается в правку сорока файлов. Библиотека компонентов исправляет расхождение у источника: одно определение, одно место для изменения, — и после первого дня она же ускоряет работу, ведь второй и третий экраны собираются, а не проектируются с нуля. Однако у этого есть цена: плохой API компонента хуже его отсутствия, потому что он распространяет свою путаницу всюду, где используется.
