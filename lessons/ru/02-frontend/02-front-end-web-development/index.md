## Что охватывает

Фронтенд-разработка — это работа над той частью приложения, которой касается человек: документ, его оформление, его поведение и конвейер, который всё это доставляет. Она охватывает языки платформы, фреймворк, которым вы их собираете, и два качества, решающие, удобен ли результат, — доступность и скорость. Обычно эту область описывают через инструменты, которые меняются, а не через эти слои, которые не меняются.

## Почему это важно

Это слой, где становится видимым каждое продуктовое решение, и слой с самой широкой аудиторией толкователей: браузер рисует страницу одному человеку, скринридер описывает её другому, поисковый робот индексирует для третьего. Правильная разметка и правильная доставка служат всем сразу, поэтому основы здесь переживают любой фреймворк.

## Входящие навыки

- **Каскадные таблицы стилей (CSS)** (`02-frontend/05-css`) — каскад, блочная модель и системы раскладки.
- **JavaScript** (`02-frontend/06-javascript`) — язык, который заставляет страницу реагировать.
- **React** (`02-frontend/29-react`) — один из распространённых способов собрать приложение из компонентов.
- **Доступность (WCAG / a11y)** (`02-frontend/11-accessibility-wcag-a11y`) — сделать результат пригодным для клавиатуры и вспомогательных технологий.
- **Веб-производительность (Core Web Vitals)** (`02-frontend/26-web-performance-core-web-vitals`) — измеряемый опыт, пока страница загружается и отвечает.

## С чего начать

Начните с CSS и JavaScript вместе: это два слоя, на которых стоит всё остальное. Добавьте React, когда язык и модель документа уже знакомы, потому что фреймворк полезнее всего тогда, когда он не учит вас попутно платформе. Доступность идёт рядом с решениями о разметке, а не после них. Веб-производительность идёт последней, когда есть настоящая страница для измерений.
