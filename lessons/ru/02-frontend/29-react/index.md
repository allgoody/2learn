## Что это такое

React — это библиотека JavaScript для построения пользовательских интерфейсов из небольших переиспользуемых компонентов. Вы описываете, как должен выглядеть экран при заданном состоянии, а React сам вычисляет минимальный набор изменений, чтобы браузер этому описанию соответствовал. Библиотека, а не фреймворк: маршрутизация, загрузка данных и стили остаются отдельными решениями, которые вы принимаете сами.

## Почему это важно

Обновление DOM вручную — источник большинства ранних ошибок фронтенда: забудете снять обработчик или обновите лишь одно из трёх мест, где живёт одно и то же значение, — и экран постепенно перестанет соответствовать данным. React убирает этот класс ошибок, потому что отрисованный результат становится чистой функцией состояния: измените состояние, и интерфейс перестроится сам. Именно поэтому он доминирует на рынке труда — ментальная модель достаточно мала, чтобы выучить её за день, и достаточно сильна, чтобы выдержать большое приложение. Вдобавок это экосистема, под которую написано всё остальное — от библиотек компонентов до инструментов тестирования.
