## Что это такое

React — это библиотека JavaScript для построения пользовательских интерфейсов из небольших переиспользуемых компонентов. Вы описываете, как экран должен выглядеть при заданном состоянии, а React вычисляет минимальный набор изменений, чтобы браузер этому описанию соответствовал. Это библиотека, а не фреймворк: маршрутизация, загрузка данных и стили остаются отдельными решениями, которые вы принимаете сами.

## Почему это важно

Обновление DOM вручную — источник большинства ранних ошибок фронтенда. Забыт снятый обработчик, обновлено одно из трёх мест, где живёт одно и то же значение, — и экран постепенно перестаёт соответствовать данным. React убирает этот класс ошибок: отрисованный результат становится чистой функцией состояния. Измените состояние — и интерфейс перестроится сам. Поэтому он и доминирует на рынке труда: ментальная модель достаточно мала, чтобы выучить её за день, и достаточно сильна, чтобы выдержать большое приложение. Это ещё и экосистема, под которую написано всё остальное — от библиотек компонентов до инструментов тестирования.
