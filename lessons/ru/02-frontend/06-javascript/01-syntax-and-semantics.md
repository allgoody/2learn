## Что это такое

Это ядро JavaScript как языка: какие значения в нём бывают, как имена связываются с ними, как функции захватывают своё окружение и как ведут себя объекты. Здесь нет ничего специфичного для браузера. Всё дальнейшее в треке — DOM, промисы, модули — это стандартная библиотека и окружение, построенные поверх этих правил.

## Почему это важно

Большинство моментов «JavaScript — странный язык» на самом деле означают «JavaScript следует правилам, о которых мне не сказали». `0.1 + 0.2` — это не сломанный язык; `this`, меняющий смысл, — не баг; переменная, равная `undefined` в начале функции, — это hoisting. Знание правил превращает набор мемов в модель, из которой можно рассуждать, а именно эта модель позволяет читать незнакомый код, предсказывать результат до запуска и объяснить коллеге, почему его проверка проходит, когда он ждал провала.

## Ключевые идеи

### У значений есть типы, и приведение происходит незаметно

В JavaScript есть примитивы (string, number, boolean, null, undefined, symbol, bigint) и объекты. `==` приводит типы перед сравнением, что даёт результаты вроде `[] == false`; `===` не приводит и потому является правильным выбором по умолчанию. Набор из шести ложных значений — `false`, `0`, `""`, `null`, `undefined`, `NaN` — источник множества неявных ветвлений.

```js
console.log(1 == "1");   // true  — приведено
console.log(1 === "1");  // false — не приведено
console.log([] == false); // true — обе стороны приведены к 0
```

### `let` и `const` блочные, `var` — нет

`var` поднимается к объемлющей функции и может быть переприсвоен из любого места внутри неё. `const` запрещает переприсваивание привязки, а не мутацию объекта, на который она указывает. Предпочитайте `const`, берите `let`, когда переприсваивание действительно нужно, и считайте `var` признаком того, что вы читаете старый код.

```js
const user = { name: "Ada" };
user.name = "Grace";   // допустимо — объект мутирует
// user = {};          // TypeError — привязку переприсвоить нельзя
```

### Функции — это значения, а замыкания захватывают переменные

Функцию можно передать, вернуть и сохранить, как любое другое значение. Замыкание — это функция, которая помнит переменные места, где она была определена, а не того, где вызвана; именно поэтому счётчик сохраняет своё значение между вызовами и поэтому переменная цикла может выглядеть «общей» для всех колбэков, построенных внутри него.

```js
function counter() {
  let n = 0;
  return () => ++n;
}

const next = counter();
console.log(next(), next());  // 1 2
```

### `this` зависит от того, как вызвана функция

Для обычной функции `this` задаётся местом вызова; для стрелочной он наследуется из места, где функция написана. Поэтому передача метода как колбэка теряет его `this`, и поэтому внутри колбэков предпочитают стрелочные функции. `bind`, `call` и `apply` задают его явно.

### Объекты и прототипы

У каждого объекта есть прототип, к которому он делегирует, когда свойства не хватает. Классы — это синтаксис для того же механизма, а методы `class` живут на прототипе, а не на каждом экземпляре. Понимание этого объясняет, почему `for...in` обходит унаследованные свойства, а `Object.keys` — нет.

## Практика

### Предскажите до запуска

Напишите пять выражений, смешивающих `==`, `===`, `null`, `undefined`, `0` и `""`, предскажите каждый результат, затем проверьте их в консоли и объясните каждое удивление одним предложением.

Готово, когда: у вас есть хотя бы один неверный прогноз и вы можете назвать правило приведения, которое его сломало.

### Постройте замыкание, которое нельзя сломать

Напишите функцию, возвращающую две функции с общим приватным счётчиком: одна увеличивает его, другая читает, — без глобальной переменной.

Готово, когда: вызов читателя снаружи всегда сообщает текущее значение, и сбросить его не может ничто, кроме инкремента.

## Частые ошибки

- **Использование `==` для сравнения** — незаметное приведение делает несвязанные значения равными; исправить: используйте `===`, если только вы намеренно не проверяете `null` или `undefined` вместе.
- **Убеждение, что `const` делает значение неизменяемым** — свойства объекта всё равно меняются; исправить: используйте `Object.freeze` там, где неизменяемость важна, или перестаньте мутировать общие значения.
- **Потеря `this` при передаче метода как колбэка** — метод запускается с неправильным получателем и падает; исправить: используйте стрелочную функцию или один раз привяжите метод через `bind`.
- **Объявление переменных через `var` внутри цикла** — каждый колбэк замыкается на одну и ту же привязку; исправить: используйте `let`, который создаёт новую привязку на каждой итерации.
- **Проверка свойства через `if (obj.value)`** — законный `0` или `""` считается отсутствием; исправить: сравнивайте с `undefined` или используйте `Object.hasOwn`.
