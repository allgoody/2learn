## Что охватывает

HTML и CSS — два языка, которые понимает каждый браузер, и вместе они составляют слой документа в вебе. HTML задаёт структуру и смысл документа; CSS решает, как эта структура выглядит и как она перестраивается, когда меняется доступное место. Их обычно называют вместе, потому что их вместе и изучают и потому что по отдельности ни один не полезен: разметка без таблицы стилей — это простой документ, а таблица стилей без разметки, которую можно выбрать, не стилизует ничего.

## Почему это важно

Всё, что находится выше этого слоя — JavaScript, фреймворки, инструменты сборки, — компилируется в эти два языка. Поэтому это самые долговечные вложения во фронтенд: соглашения фреймворка меняются каждые несколько лет, а страница с семантичной разметкой и маленькой предсказуемой таблицей стилей продолжает работать. Здесь же решается доступность, потому что дерево документа — это то, что читают вспомогательные технологии, и здесь начинается производительность, ещё до того как в дело вступает хоть один сценарий.

## Входящие навыки

- **Язык гипертекстовой разметки (HTML)** (`02-frontend/03-html`) — структура и смысл документа.
- **Каскадные таблицы стилей (CSS)** (`02-frontend/05-css`) — каскад, блочная модель и системы раскладки, которые её стилизуют.

## С чего начать

Сначала читайте HTML: выбранные элементы — это сырьё для каждого следующего правила стилей, и их семантику нельзя добавить позже через CSS. Затем пройдите трек CSS по порядку, закончив современными возможностями, которые заменили многое из того, из чего строились старые таблицы стилей. После этого адаптивный веб-дизайн применит и то и другое к настоящим экранам.
