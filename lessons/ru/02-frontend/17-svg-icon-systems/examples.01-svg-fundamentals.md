## Пример 1 — Иконка, которая не масштабируется

Иконка отрисовывается в одном размере независимо от CSS, и увеличение размера шрифта у родителя ничего не меняет. Скажите, какой атрибут задаёт координатное пространство, затем заставьте её масштабироваться как текст.

```html
<span class="icon"><svg width="24" height="24">…</svg></span>
```

```css
.icon { font-size: 2rem; }
.icon svg { width: 1em; height: 1em; }   /* на рисунок не влияет */
```

### Решение

```html
<span class="icon">
  <svg viewBox="0 0 24 24" aria-hidden="true" focusable="false">…</svg>
</span>
```

```css
.icon { font-size: 2rem; }
.icon svg { inline-size: 1em; block-size: 1em; color: currentColor; }
```

Без `viewBox` рисунок привязан к собственному размеру, с которым его экспортировали, поэтому изменение размеров элемента обрезает или размывает его вместо масштабирования путей. `viewBox` отображает внутреннюю координатную сетку — здесь 24 на 24 единицы — на отрисованный прямоугольник, и именно поэтому каждую иконку в системе можно масштабировать до любого размера в пикселях, не трогая данные пути. Размер в `em` заставляет иконку следовать размеру окружающего шрифта, так что читатель, увеличивший базовый размер текста, получает пропорциональную иконку, а `currentColor` позволяет цвету текста родителя определять заливку без правила для каждого экземпляра.

## Пример 2 — Одна встроенная иконка дважды, с двумя одинаковыми id

Иконка вставлена в два компонента. Градиент, определённый внутри неё, теперь ссылается не на тот элемент во второй копии, а её цвет задан жёстко, так что тёмная тема выглядит сломанной. Разберите обе причины, затем исправьте доставку.

```html
<svg viewBox="0 0 24 24" width="24" height="24">
  <defs><linearGradient id="g1">…</linearGradient></defs>
  <path d="M4 12h16" fill="#0f766e" stroke="#0f766e" />
</svg>
<!-- вставлено снова в другом компоненте: <linearGradient id="g1"> дважды в одном документе -->
```

### Решение

```jsx
export function SearchIcon({ title }) {
  return (
    <svg viewBox="0 0 24 24" aria-hidden="true" focusable="false">
      <path d="M4 12h16" fill="currentColor" stroke="currentColor" />
      {title ? <title>{title}</title> : null}
    </svg>
  );
}
```

```jsx
<SearchIcon />
<span className="text-brand-700"><SearchIcon /></span>
```

Встроенный SVG — это поддерево DOM, поэтому его id глобальны для документа: две копии одного градиента делают каждую ссылку неоднозначной, и вторая иконка молча заимствует определение первой. Превращение иконки в компонент либо убирает id совсем, либо ограничивает их областью, и единый источник сохраняет набор согласованным. `currentColor` устраняет вторую неисправность — жёстко заданный hex не может следовать теме, поэтому иконка выделяется в тёмном режиме, — и позволяет одному файлу обслуживать обе темы без дублирования. `<title>` выводится только тогда, когда иконка несёт информацию, а не служит декором.
