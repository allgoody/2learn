## Что это такое

AWS — крупнейшее публичное облако, и его каталог — причина, по которой «облако» трудно описать одним предложением. Оно продаёт сырые строительные блоки — виртуальные машины, блочное хранилище, виртуальные сети, идентичность — и отдельно управляемые сервисы, которые оборачивают эти блоки так, что решений остаётся меньше. Изучать AWS значит учиться выбирать слой, на котором стоять: почти для каждой потребности есть неуправляемый вариант, управляемый вариант и бессерверный вариант.

## Почему это важно

AWS задаёт словарь, которым описывают остальных провайдеров, а его документация — самая глубокая из трёх, что делает его самым дешёвым местом для изучения понятий. Это ещё и провайдер, который вероятнее всего уже используется, потому что он первый и крупнейший. Риск — затраты и разрастание: каталог огромен, бесплатный уровень заканчивается, а бесхозный аккаунт накапливает дорогие ресурсы, о создании которых никто не помнит. Понимание структуры аккаунта, а не только сервисов, — вот что этому мешает.
