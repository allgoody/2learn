## Пример 1 — Перекодируем статус, основанный только на цвете

В списке очереди состояние каждого заказа показано цветной точкой: зелёная — отправлен, красная — задержан. Коллега не может отличить одну от другой. Сохраните цвет, но сделайте статус читаемым и без него, добавив второй канал.

```text
Очередь
  #4021   ●   Бристоль
  #4018   ●   Лидс
  #4012   ●   Кардифф
```

### Решение

```text
Очередь
  #4021   ✓ отправлен    Бристоль
  #4018   ⚠ задержан     Лидс
  #4012   ✓ отправлен    Кардифф
```

Теперь каждое состояние несёт слово и отличимую форму, поэтому оно переживает дальтонизм, монохромную распечатку и экран в бликах; оттенок стал избыточным, а не несущим. Никогда не кодируйте смысл только оттенком. Обычная неудача — добавить слово, но оставить два статуса разными оттенками одного красного: это не убирает ни зависимость от цвета, ни двусмысленность между «задержан» и «не прошёл».

## Пример 2 — Строим линейку и оставляем акцент

В панели инструментов брендовый синий использован для баннера объявления, информационной панели, главной кнопки и ссылки, поэтому ничто не сигналит «кликабельно». Замените разрозненные образцы линейкой из четырёх шагов и дайте каждому цвету одну работу.

```text
Сейчас
  [ синий баннер: Пробный период заканчивается через 3 дня ]
  [ синяя главная кнопка: Обновить тариф ]
  [ синяя ссылка: Управлять тарифом ]
  [ синяя информационная панель: Что останется ]
```

### Решение

```text
blue-50   поверхность
blue-200  граница
blue-600  база: только интерактивные элементы
blue-800  текст на blue-50

  [ neutral-100 баннер: Пробный период заканчивается через 3 дня ]
  [ blue-600 главная кнопка: Обновить тариф ]
  [ blue-600 ссылка: Управлять тарифом ]
  [ neutral-50 информационная панель: Что останется ]
  [ red-600 разрушительная кнопка: Удалить аккаунт ]
```

Четыре шага лучше четырнадцати образцов, использованных по одному разу, потому что любая пара, к которой вы тянетесь, уже известна как рабочая; акцент теперь значит «кликабельно», а контрастный красный оставлен для разрушительных действий. Неудача, за которой надо следить, — акцент, просачивающийся обратно в украшение: как только баннер снова синий, главная кнопка перестаёт выделяться.
