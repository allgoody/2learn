## Пример 1 — Один компонент кнопки вместо двенадцати отдельных фигур

На двенадцати экранах есть нарисованная вручную главная кнопка, и они разошлись между собой. Превратите их в один компонент с именованными вариантами и свойством подписи, затем скажите, как предотвращается расхождение.

```text
Экраны: оплата, настройки, счета, ...           12 файлов
Кнопки: нарисованы на каждом экране, три чуть разных синих
Состояние: ни у одной не показаны hover, pressed или disabled
```

### Решение

```text
Button / Primary
  Варианты:   default, hover, pressed, disabled
  Свойства:   label (text), leading icon (boolean)
  Библиотека: страница компонентов
Правило: отредактируйте компонент один раз; каждый экземпляр следует за ним

Шаги
1. выделите отдельные кнопки и создайте один компонент
2. добавьте вариант для каждого состояния
3. назовите свойства label и icon
4. замените каждый рисунок экземпляром
```

С одним компонентом и именованными вариантами изменение мастер-компонента обновляет все двенадцать экранов, поэтому состояния остаются согласованными, а ревью проводится один раз. Обычная ошибка — нарисовать каждое состояние отдельной фигурой: это фиксирует цвет на сегодня и позволяет экранам снова разойтись уже к следующему релизу.

## Пример 2 — Файл с тридцатью страницами без названий

Файл для поиска разросся до тридцати страниц, названных по людям и датам. Никто не может найти текущую оплату. Перестройте страницы вокруг продукта и поместите ревью туда, где его найдут.

```text
Страницы: Поиск 1, Поиск 2, ... Поиски 30
          (нет страницы компонентов, нет архива)
```

### Решение

```text
Страницы
  Оплата          текущие экраны
  Аккаунт         текущие экраны
  Компоненты      библиотека и состояния
  Архив           устаревшие поиски
Комментарии: оставлены на точном фрейме, закрыты в файле
```

Называние страниц по областям продукта делает файл находимым, а одна страница компонентов и архив отделяют текущую работу от устаревшей. Сбой — оставлять каждый поиск отдельной страницей: через месяц в файле тридцать равноценных экранов, и проверяющий не может понять, какой из них продукт.
