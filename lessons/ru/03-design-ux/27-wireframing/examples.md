## Пример 1 — Список заказов, который не выигрывает взгляд

Коллега сверстал вайрфрейм страницы аккаунта. Промо-баннер на нём — самый крупный блок, а таблица заказов, ради которой страница существует, — самая мелкая. Перерисуйте серые блоки так, чтобы визуальный вес соответствовал важности, не добавляя ни цвета, ни деталей.

```text
+--------------------------------------------+
| [крупный баннер]   Бесплатная доставка от £50 |
| [боковая панель]   Фильтр по бренду (6 открыто)|
| Ваши заказы                                 |
| #4021  Бристоль  £240  Отправлен  [Просмотр]  |
| #4018  Лидс      £90   Доставлен  [Просмотр]  |
+--------------------------------------------+
```

### Решение

```text
+--------------------------------------------+
| Ваши заказы                                 |
| #4021  Бристоль  £240  Отправлен  [Просмотр]  |
| #4018  Лидс      £90   Доставлен  [Просмотр]  |
|                                             |
| Бесплатная доставка от £50                  |
+--------------------------------------------+
```

Теперь заголовок — самый крупный блок, заказы лежат прямо под ним, а баннер сжался до одной серой строки под содержимым. Пятисекундный тест прищуром первым попадает в «Ваши заказы». Обычная неудача — промо, которое увеличили по деловым причинам и никогда не перемеряли против назначения страницы: если вайрфрейму нужна стрелка, объясняющая, что важнее всего, макет неправильный.

## Пример 2 — Вайрфрейм пустого состояния с настоящими словами

Вайрфрейм выше был нарисован только для аккаунта с заказами. Новый клиент видит ту же страницу пустой, и команда не решила, что на ней написано. Сверстайте пустое состояние с реальными строками, чтобы макет проверили на их настоящей длине.

```text
Заполненное
  Ваши заказы
  #4021  Бристоль  £240  Отправлен  [Просмотр]
  #4018  Лидс      £90   Доставлен  [Просмотр]

Пустое (новый аккаунт)
  ???
```

### Решение

```text
Пустое
  Ваши заказы
  Заказов пока нет
  Здесь появятся заказы с их статусом и ссылкой на каждый.
  [ Посмотреть каталог ]
```

Три строки настоящего текста помещаются в одну колонку, и главное действие стоит прямо под сообщением, которое нужно новому пользователю. Написание реального предложения показывает, что длинная подпись переносится на две строки и сдвигает кнопку вниз, чего заглушка никогда не выявит. Пустое состояние импровизируют позже, если не нарисовать его сейчас, а ведь именно его большинство пользователей встречает первым.
