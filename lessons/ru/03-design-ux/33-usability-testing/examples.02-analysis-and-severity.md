## Пример 1 — От наблюдений к находкам

Пять сессий дали страницу заметок, которые все описывают одну и ту же горстку проблем. Список не упорядочен, поэтому действовать по нему пока нельзя. Сгруппируйте наблюдения в находки, по одному предложению каждая, с количеством, которое делает каждую свидетельством.

```text
Наблюдения, 5 сессий
  P1 кликает «Помощь», ища адрес
  P2 дважды пропускает «Ваши данные»
  P3 спрашивает, где менять адрес
  P4 находит только после открытия меню аккаунта
  P5 сдаётся и спрашивает модератора
```

### Решение

```text
Находка 1  Смену адреса не найти из раздела аккаунта — 5 из 5
Находка 2  «Ваши данные» пропускают дважды за одну сессию — 2 промаха
Находка 3  Один участник бросил задачу — 1 из 5

Количества из пяти условных сессий.
```

Группировка первого, третьего, четвёртого и пятого наблюдений в одну находку с количеством превращает четыре анекдота в свидетельство, и именно количество позволяет команде спорить о приоритете. Сохранение промаха по метке отдельной находкой не даёт вложить его в проблему с адресом, где он стал бы незаметным. Обычный провал — отчитываться о каждом наблюдении как о находке, что даёт список, с которого команда не может начать.

## Пример 2 — Оценка серьёзности по эффекту, а не по частоте

Четыре находки теперь нужно упорядочить. Одна частота поставила бы проблему с адресом первой, а редкую ошибку формы последней. Оцените каждую находку по тому, что происходит, когда она случается, затем обязуйтесь починить худшую. Сделайте упорядоченную таблицу и первое исправление.

```text
Находки из пяти сессий
  адрес не найти                     5 из 5
  ошибка при сохранении неполной формы 1 из 5
  промах по метке «Ваши данные»      2 из 5
  иконка смещена в шапке             3 из 5
```

### Решение

```text
Находка                            Количество  Эффект                 Серьёзность
адрес не найти                     5/5         задачу нельзя выполнить блокирующая
ошибка при сохранении неполной     1/5         данные потеряны; неверное действие серьёзная
промах по метке «Ваши данные»      2/5         выполнена медленно      незначительная
иконка смещена                     3/5         нет                     косметическая

Чинить худшее: добавить видимое действие «Сменить адрес» на экране аккаунта
и связать его с шагом адреса при оформлении заказа. Владелец: дизайн.
Перепроверить только задачу с адресом после изменения.
```

Ошибка формы у одного из пяти обгоняет промах по метке, потому что потеря данных стоит дороже медленного завершения, а смещённая иконка идёт последней, хотя замечена чаще всех. Оценка эффекта, а не количества, — то, что не даёт редкому блокирующему провалу остаться непочиненным. Обычный провал — ранжировать по одной частоте, что оставляет потерю данных внизу списка.
