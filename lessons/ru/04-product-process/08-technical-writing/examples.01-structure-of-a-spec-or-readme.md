## Пример 1 — Перепишите первый экран README

README небольшого инструмента открывается историей проекта. Перепишите первый экран так, чтобы «что», «зачем» и инструкция запуска появлялись до любой прокрутки, а справочный материал перешёл в таблицу.

```text
# Order Exporter

У команды финансов уже несколько лет есть ночной экспорт. Его дважды
переделывали. Этот документ описывает текущую реализацию и решения за ней.
Команда поддерживает и другие инструменты, а полную историю можно найти
ниже...

(дальше установка и настройка, тремя экранами ниже)
```

### Решение

```text
# Order Exporter
Копирует заказы в CSV для ночного задания финансов. Работает по расписанию.
Владелец: Прия, платформа поддержки. Написано в сентябре 2026.

Локальный запуск
  ...
Настройка         переменная | значение | по умолчанию
Частые сбои       симптом | причина | исправление
Заметки о дизайне почему он имеет такую форму
```

«Что» и «зачем» — это первые два предложения, читатель знает, кого спрашивать и когда документ написан, а всё, что ищут, стоит в таблице. Обычная ошибка — начинать с контекста, который был у автора, вместо ориентира, нужного читателю.

## Пример 2 — Назовите ответ в заголовке и ограничьте объём

В спецификации возвратов используются заголовки-темы, поэтому просматривающий читатель не может понять, к чему приходит любой раздел, и ничто не говорит, что работа не покрывает. Исправьте и то, и другое.

```text
Варианты заголовков для спецификации
  Соображения
  Механика возвратов
  Открытые вопросы
```

### Решение

```text
# Спецификация возвратов
Владелец: PM. Написано в сентябре 2026.
Проблема: возвраты занимают 1,5 дня; 6% выдаются неверно повторно.

Используйте книгу учёта как источник истины    (было: Соображения)
Требования   REQ-REF-01 ... по одной проверяемой строке на каждое
Что не входит мультивалютность, частичные возвраты, возвраты подарочных карт
Ограничения   существующая книга учёта остаётся источником истины
Открытые вопросы кто отвечает за отчёт о сверке?
```

Теперь заголовок называет вывод раздела, так что читатель, который только просматривает, находит решение; список «что не входит» предотвращает больше споров, чем любой другой раздел. Обычная ошибка — заголовок, называющий тему: «Соображения» ничего не сообщает читателю о том, что в нём решено.
