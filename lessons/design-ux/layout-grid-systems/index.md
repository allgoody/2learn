## What it is

A grid system is a set of columns, gutters and margins that content is placed against, plus the breakpoints at which that arrangement changes. It is what makes screens predictable: a reader learns where content starts and how wide it runs, and the same arrangement then holds on every page.

## Why it matters

Without a grid, every screen is positioned by feel and drifts a few pixels at a time until the product looks hand-made in the bad sense. With one, a designer placing a block has a small number of positions to choose from, and an engineer knows what to build without measuring. The grid also decides the measure of body text and the size of images, so it touches typography, spacing and the responsive behaviour at the same time.
