## What it is

Search engine optimisation is the work of making a page easy for a search engine to crawl, understand and rank for the queries it should answer. It is mostly technical hygiene — clean structure, fast pages, one canonical address per document — plus content that matches what people actually search for.

## Why it matters

A page nobody can find is a page that was never written. Search remains the largest source of visitors for most sites, and the technical portion of it is entirely within the front-end developer's control: the crawler reads the same HTML the browser does, so a page whose content only appears after a script runs, or whose headings are decorative `<div>`s, is a page the crawler cannot describe. Conversely, most of the technical work is the work you should already be doing for accessibility and performance, which makes it unusually good value.

## In this track
