# Backend & data

Server-side code, APIs and persistence.

Part of the [skills index](skills.md). Start here: **SQL & Relational Databases**, **Authentication & Authorization**, **API Design**.

## Languages & runtime

- **Node.JS** — Runs JavaScript on the server; one language across the whole stack.
- **Express.js** — Minimal Node web framework: routes, middleware, request handling.
- **Python Programming** — General-purpose language; dominant in scripting, data work and automation.
- **Java** — Long-lived, typed, JVM-based language with a heavy presence in enterprise backends.
- **Go** — Compiled, concurrent and simple; common for services, tooling and cloud infrastructure.
- **Server Side** — Umbrella for code that runs on the server rather than in the browser.

## APIs & integration

- **Restful API** — HTTP endpoints built around resources, verbs and status codes.
- **API Design (OpenAPI / Swagger)** — Specifying, documenting and contract-testing endpoints before building them.
- **Authentication & Authorization (OAuth2 / JWT)** — Proving who a user is, and what they are allowed to do.
- **WebSockets** — A two-way persistent connection for chat, live updates and collaboration.

## Data

- **SQL & Relational Databases** — Tables, joins, indexes and transactions; the default for structured data.
- **NoSQL** — Document, key-value and graph stores for the shapes SQL fits badly.
- **MongoDB** — The most common document database: JSON-like documents, flexible schema.
- **Database Design** — Choosing keys, relations and indexes so queries stay correct and fast.
- **Object-Relational Mapping** — Mapping objects to tables, and knowing where the abstraction leaks.
- **Prisma ORM** — Typed, schema-first ORM for Node and TypeScript projects.
- **Caching (Redis)** — Keeping hot data in memory to cut latency and database load.

## Architecture

- **Microservices** — Splitting a system into independently deployable services with clear boundaries.
- **Message Queues (Kafka / RabbitMQ)** — Asynchronous, decoupled work between services, with retries and back-pressure.
