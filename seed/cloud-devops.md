# Cloud & DevOps

Running, shipping and operating software on someone else's computers.

Part of the [skills index](skills.md). Start here: **Docker**, **AWS**, **CI/CD**.

## Cloud platforms

- **AWS** — The largest provider: compute, storage, networking and managed services.
- **Microsoft Azure** — Microsoft's cloud; strong in enterprise, .NET and Active Directory shops.
- **Google Cloud Platform (GCP)** — Google's cloud; strong in data, machine learning and Kubernetes.
- **Cloud Computing** — Renting compute, storage and services instead of owning servers.
- **Cloud Infrastructure** — The networks, instances, storage and policies that make up an environment.
- **Cloud Cost Management** — Keeping the bill sane: right-sizing, commitments, budgets and alerts.
- **Serverless Computing** — Functions and managed runtimes: no server to patch, pay per use.
- **Cloud-Native Computing** — Building for the cloud: containers, declarative config, elastic services.
- **Cloud Deployment** — Getting a built artifact onto cloud infrastructure safely and repeatably.
- **Cloud Development** — Umbrella for building software specifically for cloud platforms.
- **Cloud Applications** — Umbrella for applications that run on cloud infrastructure.
- **Application Deployment** — Umbrella for shipping an app to an environment; overlaps the three above.

## Containers & orchestration

- **Docker** — Packaging an app with its dependencies into a portable image.
- **Kubernetes** — Orchestrating containers at scale: scheduling, scaling, self-healing.
- **OpenShift** — Red Hat's opinionated Kubernetes distribution with enterprise tooling.
- **Helm** — Templating and versioning Kubernetes manifests as installable charts.
- **Istio** — Service mesh for traffic routing, mTLS and observability between services.
- **Terraform** — Declarative infrastructure as code: provision cloud resources reproducibly.

## Delivery & automation

- **CI/CD** — Automated build, test and release on every change.
- **GitHub Actions** — CI/CD and automation built into GitHub workflows.
- **Jenkins** — Long-standing self-hosted automation server; pipelines as code.
- **Azure DevOps** — Microsoft's suite: repos, pipelines, boards and artifacts.
- **Nginx** — Web server and reverse proxy for static files, TLS and load balancing.

## Operations

- **Linux Administration** — Users, permissions, processes, services and logs on a Linux host.
- **Networking Fundamentals (HTTP / DNS / TLS)** — What actually happens between a browser and a server.
- **Monitoring & Observability (Prometheus / Grafana)** — Metrics, logs and traces, so you know what broke and why.
- **Site Reliability Engineering** — Running systems against explicit reliability targets and error budgets.
- **Cloud Security & IAM** — Identities, roles and least-privilege access across cloud resources.
