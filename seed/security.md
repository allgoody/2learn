# Security & privacy

Part of the [skills index](skills.md). Start here: **Web Security (OWASP Top 10)**, **HTTPS & TLS**.

## Web security

- **Web Security (OWASP Top 10)** — The recurring classes of web flaw: injection, broken access control, XSS.
- **HTTPS & TLS** — Certificates and encryption in transit; why plain HTTP is now a hard fail.
- **Content Security Policy (CSP)** — Browser rules that block injected and third-party scripts.
- **Secrets Management** — Keeping API keys and credentials out of the repo, and rotating them.
- **Dependency Scanning (SCA)** — Watching the package tree for known-vulnerable versions.

## Privacy & ethics

- **GDPR & Data Privacy** — Lawful basis, consent, retention and the right to be forgotten.
- **Data Ethics** — What you should collect, infer and do with data, beyond what is legal.
