# Front-end

Everything that runs in the browser.

Part of the [skills index](skills.md). Start here: **TypeScript**, **React**, **Accessibility (WCAG / a11y)**.

## Core web platform

- **Hypertext Markup Language (HTML)** — The document structure of every page: semantics, headings, forms.
- **Cascading Style Sheets (CSS)** — Styling and layout: the box model, flexbox, grid, media queries.
- **HTML and CSS** — Umbrella for the pair; nothing beyond the two entries above.
- **Javascript** — The browser's programming language: DOM, events, async, modules.
- **TypeScript** — JavaScript with static types; catches mistakes before runtime, now the default for app code.
- **Responsive Web Design** — One layout that adapts across phone, tablet and desktop viewports.
- **Accessibility (WCAG / a11y)** — Building so keyboard, screen-reader and low-vision users can use it.
- **UI Components** — Reusable interface building blocks (button, modal, table) with defined props and states.
- **Browser Compatibility** — Making one feature work across Chrome, Safari, Firefox and older engines.
- **Ajax** — Fetching data in the background and updating part of the page without a reload.

## Frameworks & libraries

- **React** — Component library for UIs; the largest ecosystem and job market.
- **Vue.js** — Progressive component framework; gentler learning curve than the alternatives.
- **Angular** — Opinionated full framework with TypeScript, dependency injection and routing built in.
- **Bootstrap (Front-End Framework)** — Prebuilt grid and components; fast, recognisable, dated-looking.
- **Tailwind CSS** — Utility classes in the markup instead of hand-written stylesheets.
- **Sass** — CSS with variables, nesting and mixins, compiled down to plain CSS.
- **State Management** — Keeping shared app data consistent (Redux, Zustand, signals).
- **Motion Design** — Purposeful animation and transitions that explain change rather than decorate.
- **SVG & Icon Systems** — Scalable vector graphics and a consistent, accessible icon set.
- **Web Typography** — Loading, scaling and setting fonts so text reads well on screen.
- **Responsive Images** — Serving the right image size and format per screen and network.

## Build & delivery

- **Package Management (npm)** — Declaring, installing and versioning dependencies.
- **Webpack** — Module bundler; the long-standing default, powerful and config-heavy.
- **Vite** — Modern dev server and bundler; near-instant feedback, now the usual default.
- **SEO** — Structuring content and markup so search engines rank and display it well.
- **Generative Engine Optimization (GEO)** — Being cited correctly by AI answer engines, not just ranked by search.
- **Progressive Web Apps (PWA)** — A web app that installs, works offline and behaves like a native app.
- **Web Performance (Core Web Vitals)** — What Google measures: load speed, responsiveness, layout stability.
- **Lighthouse** — Automated audit for performance, accessibility, SEO and best practice.
- **Browser DevTools** — Built-in inspector, network, console and profiler; the main debugging surface.

## Umbrella terms

- **Front-End Web Development** — The whole discipline above; an umbrella, not a single skill.
